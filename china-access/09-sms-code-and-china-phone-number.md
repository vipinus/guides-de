# 09 · Bestätigungscodes, die nie ankommen, und chinesische Telefonnummern

## Was Sie sehen

Bestätigungscodes per SMS von Behördendiensten, Banken, 12306 (der chinesischen Bahnbuchung) und allerlei Apps lassen sich nicht an Ihr Smartphone senden oder werden gesendet, kommen aber nie an.

## Ursache

Bestätigungscodes per SMS gehen nur an chinesische Telefonnummern. Sind Sie im Ausland, haben Sie die chinesische Karte nicht dabei, oder Sie haben sie dabei, aber internationales Roaming nicht freigeschaltet, oder der Anschluss wurde wegen offener Rechnungen gesperrt. Mit der IP hat das nichts zu tun, und eine chinesische IP löst das SMS-Problem nicht.

## Lösungen

1. **Behalten Sie eine chinesische SIM-Karte**, schalten Sie vor der Ausreise internationales Roaming frei und wählen Sie einen Tarif, der die Nummer erhält. Bei den meisten Netzbetreibern ist der SMS-Empfang im Ausland kostenlos oder fast kostenlos.
2. **Ein Dual-SIM-Smartphone**: Die chinesische Karte dient nur zum SMS-Empfang, die lokale Karte für Daten, beide Karten stecken gleichzeitig.
3. **eSIM**: Einige Netzbetreiber können eine chinesische Nummer in eine eSIM umwandeln, die auf einem eSIM-fähigen Smartphone installiert wird, ohne einen Kartensteckplatz zu belegen.
4. **Virtuelle Nummern sind unzuverlässig**: Online gemietete Nummern zum Codeempfang stehen bei Plattformen oft auf der schwarzen Liste. Registrieren Sie sich damit niemals bei Behördendiensten oder Banken.

## Angekommen, aber die Bestätigung scheitert

- Bestätigungscodes gelten nur kurz, meist 5 Minuten; geben Sie den Code ein, sobald er ankommt.
- Wer an einem Tag mehrmals Codes anfordert, wird eingebremst; warten Sie eine Stunde und versuchen Sie es erneut.
- Scheitert die Gesichtserkennung, liegt es meist an der App-Version oder an der Kameraberechtigung; installieren Sie die chinesische Version der App und erlauben Sie den Kamerazugriff.
