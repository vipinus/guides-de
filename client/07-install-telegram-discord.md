# 07 · Telegram und Discord installieren

Beide sind weit verbreitete Gruppenchat-Tools, und auch unsere Supportgruppen laufen dort. Die Installation selbst ist nicht schwer; der Knackpunkt ist meist, dass sich „der App Store nicht öffnen lässt“.

## Telegram

| Plattform | So installieren Sie es |
|---|---|
| Windows / macOS / Linux / Android | Die [Kontaktseite unserer Website](https://www.leotun.com/de/contact?utm_source=github&utm_content=client-07) bietet Installationsprogramme, die mit den offiziellen Versionen identisch sind (für Android die vollständige offizielle APK, ganz ohne Google Play); Sie können auch die offizielle Website <https://desktop.telegram.org> oder Google Play nutzen |
| iOS | Nur über den App Store; zum Problem mit der Store-Region siehe [den vorigen Artikel](06-ios-app-store.md) |

Für die Registrierung brauchen Sie eine Mobilnummer, die SMS empfangen kann. Danach können Sie einen Benutzernamen festlegen, und andere müssen Ihre Nummer nicht kennen.

## Discord

| Plattform | So installieren Sie es |
|---|---|
| Windows / macOS / Linux | Offizielle Website <https://discord.com/download> |
| Android | Offiziell nur bei Google Play. Auf Smartphones, auf denen sich Play nicht installieren lässt, nutzen Sie das geteilte Paket (.apks); dafür muss zuerst der quelloffene Installer SAI installiert werden, und es unterstützt nur arm64-Geräte |
| iOS | App Store |

## Nach der Installation

- Lesen Sie vor dem Beitritt die Gruppenregeln. Die meisten Gruppen verbieten Werbung. Durchsuchen Sie vor einer Frage zuerst den Gruppenverlauf; viele Fragen sind schon beantwortet.
- Lässt es sich nicht installieren oder stürzt es beim Start ab, nennen Sie dem Support Ihre Systemversion und Ihr Gerätemodell; meist passen Modell oder Version nicht zusammen.
